01 / system identity

What this repo is

canonical

X Distribution is a local AI and technology intelligence desk. Its purpose is to turn a wide public source landscape into a reviewable editorial queue while preserving the evidence needed to understand where each signal came from.

Collect

Broad discovery

Independent source lanes gather official, social, artifact, market, startup, science, and developer signals.

Preserve

Evidence first

Collector outputs remain visible. Reports are derived views. Protected state is not casually overwritten.

Prepare

Manual editorial work

Verified-only drafting packets support a human workflow. Nothing publishes automatically.

04 / protected state

The active queue seam

high value

scripts/intelligence_queue.py is the authoritative module for data/news_queue.json. Queue behavior now has locality: URL identity, historical shape handling, duplicate provenance, recent-item filtering, metadata, and atomic persistence live behind one interface.

Why atomic writes matter

Canonical writers persist a complete temporary JSON file and replace the destination only after flushing it. Interrupted writes preserve the prior queue.

Why URL identity matters

Collectors use different URL fields. The queue seam canonicalizes host, path, query, and fragments consistently before deduplicating.

Queue document contract
{
  "metadata": {
    "description": "Active intelligence queue aggregated from configured source registry outputs",
    "max_items_kept": 1000,
    "dedupe": "canonical_url"
  },
  "last_updated": "ISO timestamp",
  "total_items": 0,
  "items": []
}
Canonical writers routed through the seam

phase1_collect.py, queue_maintenance.py, aggregate_deep_discovery.py, aggregate_news.py, final_hybrid_aggregator.py, flash_hunt.py, and merge_breadth.py.

05 / storage discipline

Evidence is not scratch

preserve
ClassMeaningRule
Canonical dataCurrent source of truth, including the active queue.Do not delete.
Raw collector outputLatest source-specific evidence.Preserve or archive after replacement.
Cache + ledgerDedupe, timestamp, and verification memory.Preserve unless intentionally resetting state.
Generated scratchTemporary diagnostics and old generated artifacts.Archive first.
Archive policy: use scripts/archive_stale_files.py. Review the dry-run manifest before applying moves. Preserve system-snapshot/.

07 / editorial safety

Discovery is not permission to publish

manual only

The active queue contains signals, not publishable truth. The editorial route now prepares packets only when a queue item carries VERIFIED or LIKELY_TRUE. Draft fields remain empty for human judgment.

Reachable safe path

x_distribution.py generate-posts calls generated_codegen.py, which emits verified-only manual packets.

Disabled unsafe path

process_news.py fails closed because its historical prototype embedded example stories and could replace protected queue state.

09 / honest edges

What remains unfinished

next
Current limitations
  1. Raw, normalized, and generated artifacts still coexist under data/.
  2. Full collection is network-dependent and can be slow.
  3. XCLI remains browser-backed and internally serialized.
  4. Reddit direct JSON can return 403; RSS fallback remains practical.
  5. Report classification is heuristic.
  6. Verification documentation is deeper than current automation.
Next architecture priorities
  1. Dual-write migration shims for data/raw/, data/normalized/, data/verified/, and data/content/.
  2. Historical source-health trends.
  3. Cross-source story clustering with evidence confidence.
  4. A durable verified-claims ledger.
  5. Report and CLI integration tests.
